# Posts-UIKit-Practice

A practice project created to demonstrate working with UIKit, Auto Layout via SnapKit, and networking via Alamofire. Focus is on functionality and correctness, not visual design.

## Features
- Fetch posts from a remote API (JSONPlaceholder)
- Display data in a table view
- Dependency Injection via initializer (service can be swapped for a mock)

## Stack
- Swift / UIKit
- Alamofire
- SnapKit
- MVC

## Requirements
- iOS 17+
- Xcode 15+
